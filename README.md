# Bảng phát âm Pinyin

App tĩnh để luyện phát âm Pinyin. Bấm vào một âm tiết sẽ phát ngay thanh 1; các thanh 2, 3, 4 có thể chọn tiếp trong bảng điều khiển phía trên.

Mở `index.html` trực tiếp trong trình duyệt, hoặc chạy server tĩnh nếu muốn thử qua localhost.

Có thể mở trang với tham số `q` để điền sẵn ô tìm kiếm, ví dụ:

`https://trantuan110191.github.io/chinese-pinyin/?q=zhong`
